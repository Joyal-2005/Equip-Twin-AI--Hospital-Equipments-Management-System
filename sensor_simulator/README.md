# EquipTwin-AI Sensor Simulator

This module simulates real-time IoT sensor telemetry for two critical hospital equipment models:
1. **VEN-001 (ICU Ventilator)**: Airway Pressure, Flow Rate, DHT11 Temperature, DHT11 Humidity, DC Voltage.
2. **DIA-001 (Hemodialysis Machine)**: Ultrasonic Air-in-Blood detector, DS18B20 Temperature, Venous Return Pressure, Conductivity.

> [!IMPORTANT]
> **Data Integrity Rule**: All telemetry generated by this module includes `"data_source": "SIMULATED"` to strictly differentiate it from physical ESP32 or serial hardware telemetry.

---

## Installation

Ensure Python 3.10+ is installed:

```bash
pip install -r requirements.txt
```

---

## Usage

### 1. Run Standard Normal Simulation
```bash
python simulator.py
```

### 2. Simulate Warning Drift Condition
```bash
python simulator.py --scenario warning --interval 2.0
```

### 3. Simulate Critical Alarm Condition
```bash
python simulator.py --scenario critical
```

### 4. Continuous Lifecycle Simulation (Cycles between Normal, Warning, and Critical)
```bash
python simulator.py --scenario cycle --interval 3.0
```

### CLI Parameters:
- `--endpoint`: Target FastAPI telemetry URL (default: `http://127.0.0.1:8000/api/v1/telemetry`)
- `--interval`: Delay in seconds between telemetry packets (default: `3.0`)
- `--scenario`: `normal`, `warning`, `critical`, or `cycle` (default: `normal`)
- `--count`: Number of iterations to transmit before stopping (`-1` for continuous)
